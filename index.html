Підказки до роботи з картою

Робота з ділянками

  • Клік на ділянку — вибирає ділянку та показує її дані
  • Ctrl + Shift + клік — створює нотатку для ділянки
  • Ctrl + F — пошук за назвою або значенням

Навігація по карті

  • Ctrl + затиснута кнопка миші — обертання карти
  • Скинути поворот карти — повертає карту на північ
  • Наблизити / Віддалити — наближення та віддалення
  • Показати моє місце розташування — центрує карту за місцем знаходження

Полігони

  • Полігон — малювання полігону; клік додає точку
  • З’єднати першу і останню точку або Enter — завершити полігон
  • Видалити — видалити вибраний полігон
  • Надіслати полігон — надсилає зону менеджеру для розрахунку ділянок

Створення об'єктів

  • Створити ділянку — кадастрова ділянка на карті
  • Створити поле — контур обробітку

Аналітика

  • Технічні втрати — відображення на карті
  • Необґрунтований обробіток — обробіток поза межами ділянок
  • Режим порівняння — двоекранний режим карт

Дані та налаштування

  • Експорт / Імпорт — завантаження даних у Excel або в систему
  • Шари компанії — колір товаровиробників
  • Шари полів — редагування контурів полів

Атрибутивна панель (знизу)

  • Розширити земельний банк, Супутник, Ділянки з моЄ
  • Загальна карта / Карта терміну дії, Нотатки, Завантажити карту (PDF/JPEG)

Запити в реєстр

  • Додати новий — створити запит
  • Іконка локації — розташування ділянок на карті
  • Червона стрілка — завантажити інформацію в Excel
  • Поповнити баланс — для створення запитів

Рейтинг

  • Клік на товаровиробника — закінчення договорів оренди
  • Клік на КОАТУУ — закінчення договорів по року
  • Клік на рік — ділянки на карті
  • Червона стрілка — експорт у Excel

Технічні втрати

  • Фільтр «За суб'єктом» → товаровиробник → Обрахувати
  • Клік на кадастровий номер — знайти ділянку на карті
  • Ctrl + клік на ділянку — підсвітити технічні втрати
  • Кнопка «Експорт» — завантажити дані в Excel

Необґрунтований обробіток

  • Ctrl + клік на штрихпунктир — детальна інформація
  • Кнопка «Експорт» — дані в Excel
